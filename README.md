# Personal Portfolio Website

This repository contains the source code for my personal multi-page portfolio website hosted with GitHub Pages.

## Website Purpose

The purpose of this website is to present my academic background, technical skills, research experience, projects, and professional interests in a clear and organized way.

The website is designed as a developer portfolio with a modern visual style inspired by clean portfolio layouts and journey-based storytelling.
